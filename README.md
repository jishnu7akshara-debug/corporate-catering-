# Annam — Authentic South Indian Corporate Catering Website

A modern, high-performance, responsive corporate catering website built for offices, tech campuses, executive boardrooms, and company celebrations.

## ✨ Features

- **Hero Slider**: Crossfade transitions with subtle Ken Burns scale effects, live captions, and interactive navigation dots.
- **Interactive Weekly Menu Tabs**: Dynamically switch between Tiffin & Breakfast, Daily Meals, Events & Biryani, and Sweets & High Tea with real-time course lists and dietary badges.
- **Behind-The-Scenes Kitchen Video**: Built-in video player with custom play/pause and sound controls showcasing live kitchen operations.
- **Infinite Marquee Gallery**: Smooth, continuous 18-card photo ticker of corporate spreads, banquets, and chafing counters (pauses on hover).
- **Interactive FAQ Accordion**: Expandable Q&A section with smooth height transitions.
- **Quote & Proposal Forms**: Interactive quick-quote calculator and full proposal request form with instant confirmation feedback.
- **Responsive & Lightweight**: Pure vanilla JavaScript and modern CSS with zero external dependencies required.

## 🚀 Getting Started

Simply open `index.html` in any web browser, or serve it with any static server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

A standalone single-file version is also included: `Corporate Catering Website – Home.html` (all media and fonts embedded directly as data URIs).
